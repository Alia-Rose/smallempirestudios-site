# Small Empire Studios website

The live one-page studio website for Small Empire Studios at smallempirestudios.com: shows the apps built so far, apps in the works, and a contact button for app ideas.

| Item | Value |
|---|---|
| Status | Live; last commit 2026-03-05 |
| Repo | github.com/Alia-Rose/smallempirestudios-site (public) |
| Stack | One static HTML page with inline CSS and JS; Google Fonts (Plus Jakarta Sans); no build step |
| Run / build | No build. Preview: open `index.html` in a browser. Deploy: push to `main` (GitHub Pages publishes automatically) |
| Live at | https://smallempirestudios.com |
| Key folders | `index.html` (whole site), `assets/` (app icons), `CNAME` (custom domain) |
| Page sections | Hero, Philosophy, Things We've Built (Kickbox Bootcamp), What's Next (pipeline of upcoming apps), Got an App Idea? (email button), side nav dots |
| Links out | Kickbox Bootcamp closed beta sign-up at kickboxbootcamp.smallempirestudios.com/beta |
| Related repos | `kickboxbootcamp-site` (the Kickbox Bootcamp app's own site); `small-empire-studios` (older repo, not the live site) |

## Notes go here when
- A new app is added to the studio, or a pipeline app changes name, icon or status
- Kickbox Bootcamp moves from closed beta to public on Google Play (swap the beta button back to a store link)
- Studio wording, design, colours or layout change
- The contact method or domain changes
